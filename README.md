# ДЗ 1 - постановка задачи, метрика, EDA

## Датасет

Используется **Breast Cancer Wisconsin (Diagnostic)** — табличные данные по измерениям клеточных ядер (опухоль молочной железы) и метке диагноза.

- **Объект наблюдения:** одна строка — одно обследование / образец.
- **Целевой признак:** `diagnosis` — бинарная метка: `M` (malignant, злокачественная) и `B` (benign, доброкачественная).
- **Признаки:** 30 числовых показателей (средние, стандартные ошибки и «худшие» значения по группам измерений: радиус, текстура, периметр, площадь, гладкость, компактность, вогнутость и т.д.).
- **Идентификатор:** столбец `id` — служебный, в признаки для модели не включается.

Данные взяты из репозитория **UCI Machine Learning Repository** (Diagnostic variant, файл `wdbc.data`). В коде загрузка выполняется **по прямой ссылке** на этот файл; при необходимости датасет можно скачать вручную с той же страницы.

**Страница и описание датасета (официальный источник):**  
<https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data>

**Прямая ссылка на файл, который читает код:**
